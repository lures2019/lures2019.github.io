ZAYDEN’S TREEHOUSE / 02

私密空间

记录照片、视频、日记和论文进度，选择要分享的内容。

自动备份尚未启用。资料仍可在当前浏览器加密保存，也可以下载加密备份。

私仓自动备份

首次或换设备时，先连接 GitHub，再输入原来的资料库密码。保存后自动上传加密备份。

打开资料库

新建资料库时请设至少 16 位密码。恢复备份时输入备份的原密码。

打开 GitHub 私仓 ↗

加密备份可提交到自己的 GitHub 私人仓库。工作副本保存在当前浏览器，十分钟无操作会锁定。

添加记录

导入时生成 WebP，最长边 1600 像素。

MP4 或 WebM，每个文件最多 120 MB。播放时才下载。

每条记录最多 16 个附件。

    我的记录

    勾选愿意分享的记录，再生成分享。

    生成密码分享

    每个分享使用独立密码。将加密文件发布到博客后，再把链接和密码交给对方。

    管理已生成的链接

    关闭链接后，访客无法再从链接下载。已经下载的文件仍能用原密码打开。
