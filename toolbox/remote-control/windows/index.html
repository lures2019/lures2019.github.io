Zaydenの树屋/百宝箱

远桌 · Windows 客户端

用 Windows 10/11 x64 电脑发起或接受远程协助。客户端需要 Microsoft Edge WebView2 Runtime。

下载 Windows 便携包打开网页版 ↗

一次性协助

  1. 解压并运行 YuanZhuo.exe，在共享方电脑选择「共享本机」。
  2. 保留预填的树屋公网信令地址，生成一次性邀请。通过私聊发送邀请，对方用网页控制端或 Windows 客户端发起连接。
  3. 两端核对六位确认码，由共享者选择屏幕及本次允许的操作。文件接收另行确认。
  4. 使用「停止共享」结束会话。共享方也可以按 Ctrl + Alt + Shift + F12 立即撤销控制。

复制文件和远程快捷键

  • 共享方同意连接时勾选「允许文件传输与文件剪贴板」。在任一端的 Windows 资源管理器里复制文件，再在远桌文件面板点「发送剪贴板文件」。对方点「接收并复制」后，可在目标文件夹按 Ctrl+V。新版两端可一次传输最多 16 个文件，合计 128 MiB。
  • 在远程画面中对选中的文件按 Ctrl+C，控制端会收到发送请求。Windows 控制端选「接收并复制」，网页控制端接收后使用下载链接。网页也可拖入、选择或粘贴浏览器能读取的文件。
  • 鼠标移入画面后，可以悬停在远程任务栏图标上，再点缩略图选择窗口。「远程快捷键」菜单可切换窗口、打开任务视图（Win+Tab）、切换浏览器标签页或打开任务管理器。全屏时仍能使用这个菜单。
  • 便携版无法调用 Ctrl+Alt+Delete 的 Windows 安全屏幕。若目的是打开任务管理器，可以使用菜单里的 Ctrl+Shift+Esc。

长期配对与固定密码

  1. 在被共享的电脑打开新版 YuanZhuo.exe，选「共享本机 → 长期配对 → 开始等待配对电脑」，保留预填的树屋服务地址。
  2. 展开「创建带密码的设备链接」，设置至少 12 个字符的密码，点「生成设备链接」，将链接复制到另一台电脑并收藏。可以用一句自己容易记住的长句。
  3. 下次打开同一收藏，输入同一个密码，点「发起连接」。两端核对六位确认码，共享方点「同意并选择屏幕」。共享电脑重开软件后，再点「开始等待配对电脑」即可沿用原链接。
  4. 两端都用 Windows 客户端时，也可直接复制完整配对码，在控制端勾选「连接后将配对码保存在此 Windows 账户」。成功连接一次后即可从「已配对的电脑」进入。
  5. 要让旧链接和旧配对码一起失效，在共享端停止等待，进入「管理本机长期配对码 → 更换配对码」。仅重新生成一个密码链接会保留此前的链接。忘记密码可以在共享端创建新链接。

单位网或手机热点连不上时

先在控制端点「检测信令服务」，共享端也可在同一台电脑打开网页运行检测。两端都显示可达时，再核对服务地址、邀请是否有效，以及共享端是否仍在等待。页面出现六位确认码，说明双方已交换连接请求。

若有一端无法访问树屋服务，可以在双方获准使用远程协助的网络上进行一次性手动连接。两端只需能私发文本，并允许设备之间建立 WebRTC 连接。

  1. 共享方在新版 Windows 客户端选「共享本机 → 手动交换连接信息 → 生成手动连接邀请」，把「复制邀请链接」得到的链接私发给对方。
  2. 控制方打开链接，点「发起连接」，把页面生成的「连接请求」发回。共享方粘贴后核对六位码，点「同意并选择屏幕」。
  3. 共享方将「共享应答」发给控制方。控制方粘贴后，把「连接回执」发回共享方。共享方粘贴回执后，两端开始建立画面连接。
  4. 若已交换回执仍然没有画面，问题处在设备直连阶段。单位网络可能需要管理员允许 WebRTC 或提供获准使用的 TURN 中继。当前公共服务只负责介绍两端，未开通按流量收费的媒体中继。

双方已配对，却一直没有画面

「检测信令服务」只检查连接请求能否送达。收到共享应答以后，画面通过 WebRTC 直连或 TURN 媒体中继传送。手动交换信息也使用同一套画面通道。

  1. 控制端在「本机媒体中继」填写自己的 TURN 地址、用户名和密码。共享端可在「网络设置 · 信令与媒体中继」填写本机凭据。每台设备只读取自己的配置。直连时可以留空。
  2. 点「测试媒体中继」。看到「已取得 TURN 中继线路」，表示这台设备已拿到线路。两端来自不同网络时，请分别测试。
  3. 测试时可以勾选「本次只用本机中继」，再生成邀请并连接。画面工具栏显示「TURN 中继」，即可确认会话走了中继。测试完成后可以取消勾选，让远桌尝试直连。

使用自己的 Cloudflare TURN

  1. 在自己的 Cloudflare Realtime 控制台 创建 TURN Key。参考 Cloudflare 凭据说明。
  2. 在新版 Windows 客户端打开「我的 Cloudflare 中继」，输入 TURN Key ID 和 TURN Key API Token，点「验证并保存」。远桌会为此 Windows 账户加密保存密钥，等到连接时向 Cloudflare 申请临时凭据。
  3. 经常使用的两台 Windows 电脑可以各设置一次。使用自己信任的浏览器临时接入时，在 Windows 客户端点「复制网页临时凭据」，到网页的「本机媒体中继」里粘贴。临时凭据有效期为 4 小时，关页后需重新填写。
  4. 私人配置由各设备单独保存。百宝箱访客可以直接尝试直连，也可以填入自己的 TURN。当前用量和超额费率可在 Cloudflare Realtime 定价 和账户用量看板查看。

跨网使用

127.0.0.1 只适合同机测试。一次性邀请和长期配对默认连接树屋的免费 HTTPS 信令服务。屏幕和文件默认通过设备直连传输，也可使用已配置的媒体中继。长期开启的配对设置可以在本机的配对管理中撤销。

便携包另附 YuanZhuo-Signal.exe，供有公网 HTTPS 入口的用户自托管。在服务器上启动信令进程，将已有的 HTTPS 反向代理转发到本机 8787 端口，再把自己的 HTTPS 地址发给参与协助的双方。日常使用直接保留客户端预填的树屋地址即可。

.\YuanZhuo-Signal.exe -listen 127.0.0.1:8787 -origins https://lures2019.github.io
