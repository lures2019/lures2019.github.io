等待连接

连接前的三个步骤

  1. 在被控电脑的 Windows 客户端中选择「共享本机」。
  2. 复制信令地址和密钥，在这里粘贴。
  3. 与对方核对六位确认码，由对方开始共享。
关于跨网连接

一次性邀请使用树屋的免费公网配对服务。双方需要能通过 WebRTC 直连。校园网或公司网限制直连时，可以更换网络。长期配对支持自备信令服务。

共享权限

默认由本机确认连接。先登记你自己的 Windows 控制端，再开启免确认等待。

按 Ctrl + Alt + Shift + F12 可在本机立即撤销共享。

共享端需保持应用运行、电脑处于唤醒状态并开启等待接入。
