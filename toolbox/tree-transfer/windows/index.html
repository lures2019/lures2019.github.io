树屋快传 · Windows 离线版

两台 Windows 10/11 x64 电脑即使没有互联网，也能通过局域网、热点、网线或经典蓝牙互传文件。

下载 Windows 便携包打开网页版 ↗

第一次传文件

  1. 双方解压便携包，分别运行 tree-transfer-windows-x64.exe，选择接收目录。
  2. 选相同的连接方式。局域网用户接同一个路由器；热点用户加入同一个热点；蓝牙用户先在 Windows 设置中配对。
  3. 一方点「生成配对密钥」，另一方粘贴并点击「连接」。
  4. 选择或拖入文件，对方核对清单并确认。传完后软件校验文件内容，再保存到接收目录。

两台电脑在不同地方

两人都打开网页快传，保持页面在线。网页和 Windows 离线版使用不同的配对方式。校园网、公司网可能限制设备直连，可以换到允许直连的网络。浏览器的下载受本机磁盘和可用暂存空间限制。
