Zaydenの树屋/百宝箱

松间 · Windows 自习室

最多 6 人开会或自习。可同时共享多块屏幕、开麦、聊天，并在白板上一起写画。

下载 Windows x64 便携包打开网页版 ↗

创建或加入

  1. 完整解压 ZIP，在解压后的目录运行 Studyroom.exe。程序旁边的 resources 和其他文件需要保留。
  2. 创建会议，把会议码或邀请链接私发给同伴。也可以在网页会议大厅加入。
  3. 入会时麦克风和摄像头默认关闭。打开「共享屏幕」后自己选择希望分享的窗口；点击某位同伴的画面可放大观看。
  4. 房主可锁定会议、管理发言或结束房间。白板如需保留，可以在离开前导出 PNG。

连通性

会议码用于加入房间，语音和屏幕通过 WebRTC 在设备之间传输。受限制的网络可能出现能入会但看不到对方画面的情况，可以换用移动热点重试。演示模式可在单机上体验界面和白板。
