站主下载入口

先用站主账号 lures2019 登录 GitHub，再打开 Flowline 1.1.0 私仓下载草稿。若页面显示 404，请确认当前登录的是站主账号。

草稿中逐个标明了文件用途、适用设备和打开方式。展开页面下方的 Assets（附件），即可找到 Windows x64、Windows ARM64、Chrome / Edge 扩展、Android 安装包和 SHA256SUMS.txt 校验清单。

使用说明

首次打开程序会读取公开订阅并执行连通性测试。启动前请确认所在网络允许这些操作。学习时可使用自己管理或已明确获准使用的节点，在「设置 → 添加 HTTPS 订阅」填入地址，再点「更新节点」。节点列表默认显示近期复测通过的线路。

Windows 客户端

  1. 选择与处理器匹配的 x64 或 ARM64 包，完整解压后运行 Flowline.exe。
  2. 在「节点雷达」查看延迟并选择获准使用的线路。规则模式按域名规则分流，全局模式让进入客户端的流量经过所选节点，直连模式直接连接目标。
  3. 仅在需要接管 Windows 测试流量时开启「系统代理」。实验完成后关闭代理，再退出客户端。

Chrome / Edge 扩展

  1. 保持 Windows 客户端运行，在其「设置」中复制配对码。
  2. 打开浏览器的扩展管理页，开启开发人员模式，加载解压后的 Flowline-Chromium 文件夹。
  3. 打开扩展，完成配对，再按需启用「浏览器代理」。完成实验后关闭该开关。配对码请自行保管。

Android 客户端

  1. 在 Android 8.0 或更高版本的 ARM64 或 x86 设备安装签名 APK。
  2. 打开应用，选用获准使用的节点。需要接管设备流量时，开启「系统 VPN」并在 Android 权限提示中确认。
  3. 实验完成后关闭「系统 VPN」。

安装包校验

站主取得文件后，可用 PowerShell 的 Get-FileHash -Algorithm SHA256 查看文件摘要，并与私有下载目录中的 SHA256SUMS.txt 对照。
